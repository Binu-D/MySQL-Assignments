MySQL Assignment 1 – DDL Commands & Constraints

About the Assignment
This assignment focuses on understanding and implementing Data Definition Language (DDL) commands and constraints using MySQL.

Tools Used
- MySQL Workbench

Topics Covered

DDL Commands
- CREATE DATABASE and CREATE TABLE
- ALTER TABLE
- RENAME TABLE
- TRUNCATE TABLE
- DROP TABLE and DROP DATABASE

 Constraints
- PRIMARY KEY
- UNIQUE
- NOT NULL
- AUTO_INCREMENT
- CHECK
- DEFAULT
- FOREIGN KEY
- ENUM

Database Tables
1. Departments
2. Location
3. Employees

Concepts Practiced
- Database and table creation
- Modifying table structures
- Renaming and deleting tables
- Applying constraints
- Establishing relationships between tables using foreign keys

Learning Outcome
Gained practical experience in creating and managing relational database structures using MySQL and implementing constraints to maintain data integrity.
